2. Original exact issue

Following the high-level docs example, creating a dataset with: 

authors=[{
    "name": "Jane Smith",
    "affiliation": "University of Science",
    "identifier_scheme": "ORCID",   # <-- triggers crash
    "identifier": "0000-0000-0000-0000",
}]

raised during payload conversion (to_dataverse_create_dict()), not during author assignment: 

TypeError: issubclass() arg 1 must be a class
  File ".../metadata.py", line 295, in _process_field_value
    if issubclass(field_info.dtype, CompoundField):

Reporter workaround (commenting out identifier_scheme) “worked” only because empty nested CV fields are skipped before _process_field_value runs — so Identifier Type never reached the buggy issubclass call.

3. What was parsed / handled wrong (before the fix)

3.1 Controlled vocabulary dtype is not a class

CV fields are built as Optional[Annotated[str, AfterValidator(...)]] in builder._cv_type_from_values. After optional unwrap, nested field authorIdentifierScheme still has dtype: 

typing.Annotated[str, AfterValidator(...)]
isinstance(dtype, type) == False
get_origin(dtype) == typing.Annotated

Re-checked on the fixed tree (dtype shape is unchanged; only the guard changed): calling bare issubclass(dtype, CompoundField) still raises: 

ISSUBCLASS_RAW_ERROR: issubclass() arg 1 must be a class

3.2 Broken code path

4. Exact code fix

File: pyDataverse/dataverse/connect/metadata.py · function: MetadataBlockBase._process_field_value

Before

if issubclass(field_info.dtype, CompoundField):
    if field_info.multiple and isinstance(value, list):
        return [field.to_metadata_fields() for field in value]
    return value.to_metadata_fields()

return value

After

dtype = field_info.dtype
if isinstance(dtype, type) and issubclass(dtype, CompoundField):
    if field_info.multiple and isinstance(value, list):
        return [field.to_metadata_fields() for field in value]
    return value.to_metadata_fields()

return value
For Annotated[...] CV dtypes, isinstance(dtype, type) is False, so the method returns the string value unchanged (e.g. "ORCID"). Downstream _create_metadata_field then wraps it with typeClass=controlledVocabulary.

Verified present at line 290:

290:        if isinstance(dtype, type) and issubclass(dtype, CompoundField):
